# KnowDesk

Your Knowledge, On Your Desk.

증권사 임직원이 개인 PC에 쌓아둔 업무 매뉴얼·규정집·리서치 자료·회의자료 등을 전역 단축키로 즉시 호출해 본문까지 검색하는 로컬 검색 플랫폼이다. 인터넷 연결·외부 API·중앙 서버 없이 개인 PC 안에서만 동작한다.

개발·빌드·수동 검증 절차는 `DEVELOPMENT.md` 참조.

---

## 시작하기

실행하면 트레이(메뉴 바) 아이콘만 나타난다 - 작업 표시줄/Dock에는 뜨지 않는다. 이미 실행 중일 때 다시 실행하면 새 프로세스가 뜨지 않고 기존 창이 앞으로 나온다.

첫 실행 시 기본값으로 `settings.json`이 자동 생성된다. 색인 대상 폴더(`watched_folders`)가 기본값으로 비어 있으므로, 검색이 되려면 먼저 아래 "설정"에서 폴더를 최소 하나 등록해야 한다.

검색창은 전역 단축키(기본 `Ctrl+Alt+K`, macOS는 `⌘+Option+K`)나 트레이 아이콘 좌클릭으로 부른다.

## 설정

트레이 메뉴의 **Settings**, 또는 검색창에서 `Ctrl+,`(macOS `⌘+,`)를 누르면 `settings.json`이 OS 기본 편집기(텍스트 에디터)로 열린다. 별도의 설정 창은 없다 - 이 파일을 직접 편집하고 저장하면 된다.

파일을 직접 찾아야 할 때의 기본 위치:

| OS | 경로 |
|---|---|
| macOS | `~/Library/Application Support/KnowDesk/settings.json` |
| Windows | `%LOCALAPPDATA%\KnowDesk\settings.json` |
| Linux | `~/.local/share/KnowDesk/settings.json` (`$XDG_DATA_HOME` 설정 시 그쪽) |

저장하면 대부분 앱을 재시작하지 않아도 바로 적용된다 (`watched_folders`/`hotkey`/`file_watch_debounce_ms`/`auto_start`는 즉시 반영. 나머지는 검색창을 다시 열 때 반영).

| 필드 | 기본값 | 설명 |
|---|---|---|
| `watched_folders` | `[]` | 색인하고 계속 감시할 폴더의 절대 경로 목록. 예: `["C:\\문서\\리서치"]`. 비어 있으면 아무것도 색인하지 않는다. |
| `theme` | `"system"` | `"light"` / `"dark"` / `"system"`(OS 설정 따라감) |
| `hotkey` | `"CmdOrCtrl+Alt+K"` | 검색창을 부르는 전역 단축키. |
| `result_limit` | `0` | 검색 결과 표시 개수 상한. `0`은 무제한. |
| `search_debounce_ms` | `150` | 입력을 멈춘 뒤 실제 검색이 실행되기까지 대기 시간(ms). |
| `file_watch_debounce_ms` | `3000` | 감시 중인 폴더에 변경이 생긴 뒤 실제로 재색인하기까지 대기 시간(ms). 문서 저장 중 생기는 임시파일 폭주에 대응. |
| `auto_start` | `false` | `true`로 바꾸면 OS 로그인 시 자동 실행. |
| `max_file_size_mb` | `50` | 이보다 큰 파일은 색인에서 제외. |

지원하는 문서 형식: Word(`.docx`), Excel(`.xlsx`), PowerPoint(`.pptx`), PDF, 일반 텍스트(`.txt`), 마크다운(`.md`). 구버전 포맷(`.doc`/`.xls`/`.ppt`)은 지원하지 않는다.

## 단축키

**전역** (앱이 어디서든 동작, 트레이로 숨어 있어도 동작):

- `Ctrl+Alt+K` (macOS `⌘+Option+K`, `hotkey` 설정으로 변경 가능) - 검색창 호출/숨김
  - 창이 보이고 포커스도 있으면 → 숨김
  - 창이 보이지만 포커스가 없으면 → 포커스만 가져옴
  - 창이 숨겨져 있으면 → 보이기 + 포커스

**검색창 안에서**:

| 키 | 동작 |
|---|---|
| `↑` / `↓` | 결과 목록 이동 |
| `Enter` | 선택한 파일 열기 |
| `Ctrl+Enter` (`⌘+Enter`) | 선택한 파일이 있는 폴더 열기 |
| `Ctrl+C` (`⌘+C`) | 선택한 파일의 경로 복사 |
| `Ctrl+1` / `Ctrl+2` (`⌘+1` / `⌘+2`) | 내용 검색 / 파일명 검색 모드 전환 |
| `Ctrl+,` (`⌘+,`) | 설정 파일 열기 (트레이 메뉴 Settings와 동일) |
| `Esc` | 창 숨기기 (완전 종료가 아니라 트레이로 숨김) |

## 트레이 메뉴

- **Settings** — `settings.json`을 기본 편집기로 열기
- **Statistics** — 색인된 문서 수(본문 색인/메타 색인), 색인 DB 용량, 마지막 색인 시각을 보여줌
- **Reset Index** — 색인을 전부 지우고 감시 중인 모든 폴더를 처음부터 다시 색인 (확인 대화상자 필요, 되돌릴 수 없음)
- **Quit** — 완전 종료

## 검색 문법

검색창에 검색어를 입력하지 않은 상태면 문법 도움말이 화면에 그대로 표시된다. 요약:

- `채권 발행` — 두 단어 모두 포함 (공백은 `AND`와 같은 뜻)
- `채권 OR 회사채` — 둘 중 하나라도 포함
- `채권 NOT 국채` — 앞 단어는 포함, 뒷 단어는 제외
- `(채권 OR 회사채) AND 발행` — 괄호로 우선순위 지정 (괄호 없으면 `AND`가 `OR`보다 먼저 묶임)
- `"채권 발행"` — 띄어쓰기까지 정확히 일치하는 구문만
- `발행*` — "발행"으로 시작하는 모든 단어

필터(검색어와 함께 입력, 내용 검색·파일명 검색 모두 적용):

- `x:pdf` — 확장자로 좁히기
- `p:리서치` — 경로에 이 문자열이 포함된 문서만
- `m>2026-01-01` / `m<2026-08-01` / `m=2026-08-10` — 수정일 이후/이전/정확히 일치

자세한 문법은 `docs/05_Search_Language_v1.md` 참조.
