# KnowDesk Open Issues v1.1

## 문서 목적

PRD에는 확정된 사항만 포함한다.

향후 확인 또는 의사결정이 필요한 사항의 **단일 출처는 `KnowDesk_추가검토사항.md`**다. 이 문서(`02`)는 기존에 별도의 O/R 목록을 유지했으나, `추가검토사항.md` Part A(승인 선결 사항)·Part C(리스크)와 ID가 겹치면서 서로 다른 내용을 가리키는 충돌이 발생했다(예: 양쪽의 R-1~R-3가 서로 다른 리스크). v1.1부터 목록 중복을 제거하고 이 문서는 요약 + 참조만 남긴다.

---

# 결정 현황 요약

상세는 `KnowDesk_추가검토사항.md` 상단 "결정 현황 업데이트" 표 참조. 요약:

- D-1(문서 식별자): SHA256 내용 해시 확정
- 원문 저장 정책: HMAC 폐기, 원문 평문 저장 허용
- 배포 형태: 단일 실행 파일 폐기 → 인스톨러
- 기술 스택: Rust + Tauri 2 확정
- D-3(형태소 분석): Kiwi 채택, bigram 폴백으로 시작
